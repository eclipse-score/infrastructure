# How To Use This Documentation

This site is intended to be used quickly, not read front-to-back.

## Choose A Navigation Mode

- by area: use [Platform Areas](../source/overview.md) if you already know the capability you work in
- by task: use [Guides](../guides/overview.md) if you want to complete a concrete task

## Recommended Reading Path

1. Start with [Platform Overview](../start-here/platform-overview.md).
2. Open either [Capability Map](../start-here/capability-map.md) or [Work Breakdown Structure](../work-ahead/work-breakdown-structure.md), depending on whether you need structure or work visibility.
3. Continue into a platform overview or guide page.

## When Information Is Incomplete

Some areas are still evolving. In those cases:

- use the work package links to understand current direction
- prefer neutral assumptions
- update the page when implementation becomes clear

## Keep Pages Connected

When you update a page, also update links to:

- related guides
- related work packages
- related platform areas

This keeps the site usable for both task-driven and area-driven readers.

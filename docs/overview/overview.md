# Overview

This documentation describes how S-CORE infrastructure is structured and how to work with it.

It is designed for practical use by developers, infrastructure contributors, managers, and compliance-oriented readers.

## What You Can Do Here

- understand the platform structure without reading every repository
- find task-oriented guidance for common infrastructure work
- see what work packages exist and where support is needed
- review capability boundaries and cross-cutting concerns

## Documentation Model

- [Start Here](../start-here/platform-overview.md): onboarding path and platform context
- [Work Ahead](../work-ahead/work-breakdown-structure.md): work map, contribution map, and current focus
- [Platform Areas](../source/overview.md): stable capability model across source, build, CI/CD, artifacts, testing, security, documentation, and operations
- [Guides](../guides/overview.md): task-oriented instructions
- [Architecture](../architecture/platform-model.md): platform model, tool landscape, and cross-cutting concerns

## How To Navigate

Use one of two primary paths:

- by area: start from a platform overview page
- by task: start from the guides overview page

If you are new, begin at [Where to start](where-to-start.md).
